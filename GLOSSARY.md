# Glossary — quick definitions

- CI: Continuous Integration — automatically building and testing code on each change.
- CD: Continuous Delivery / Continuous Deployment — automatically releasing tested changes to environments.
- Pipeline: A sequence of automated steps (build, test, deploy).
- Workflow: In GitHub Actions, a YAML file under `.github/workflows/` that defines when jobs run and what they do.
- Job: A grouping of steps that run on a single runner.
- Step: A single command or action inside a job.
- Runner: The virtual machine or container that executes your job steps (GitHub-hosted or self-hosted).
- YAML: A human-readable data-serialization format used by workflows.
- Branch: An independent line of development in Git.
- Commit: A saved change in Git history.
- Push: Send local commits to a remote repository (GitHub).
- Pull Request (PR): A request to merge changes from one branch into another, commonly used for code review.

# Contributing to CI/CD Blueprint

Thank you for offering to help! Small, clear steps are best for documentation projects.

How to contribute

1) Fork the repository
2) Create a branch: `git checkout -b docs/fix-some-typo`
3) Make your change and commit with a clear message
4) Push and open a Pull Request from your branch

What we look for

- Clear, beginner-friendly language
- Step-by-step commands that are copy-paste friendly
- Explanations for unfamiliar terms on first use

If you fix a lab, please run it locally or in a fork so we can confirm the commands work.

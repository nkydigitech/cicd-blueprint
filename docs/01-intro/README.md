# Module 01 — Introduction to CI/CD

What is CI/CD?

- Continuous Integration (CI): the practice of automatically building and testing code whenever changes are made so that problems are discovered early.
- Continuous Delivery / Deployment (CD): the practice of automatically delivering or deploying tested changes to production or staging environments.

Why this matters

CI/CD turns slow, risky, manual deployments into repeatable, automated processes. That means fewer "3 AM" incidents, faster feedback, and more reliable software.

What you'll learn in Module 01

- What a pipeline is and how it runs
- How to add a GitHub Actions workflow to a repo
- How to read build logs and troubleshoot simple failures
- How to clean up after a lab

How long this module takes

- ~20–45 minutes for the hands-on lab depending on your familiarity with Git and the terminal.

Who this is for

- Complete beginners who can use a browser and copy-paste commands into a terminal.

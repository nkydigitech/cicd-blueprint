# Roadmap and Module Map

This repo is designed to take you from zero to confident practitioner. Modules are short, hands-on, and focused on practical skills.

Planned modules (order may change):

1. Introduction to CI/CD (this module)
2. Build & Test: run real unit tests in CI (Node/Python examples)
3. Deployment: GitHub Pages and simple static site deploys
4. Pipeline as Code: reusable workflows and actions
5. Deployment strategies: blue-green, canary, rolling (concepts + demos)
6. Secrets and environment management
7. Integrating IaC: run Terraform/Ansible from CI safely
8. Monitoring & rollback strategies

Each module contains:
- A short conceptual README
- A hands-on lab with step-by-step instructions
- A small quiz/checkpoint and troubleshooting tips
- Cleanup instructions where needed
